<h1>Layer 2 Vlan</h1>

<h2>Description</h2>
Short Layer 2 Vlan project where each workstations are connected to the same switch, but are logically segmented. This creates a separation of broadcast domains by assigning the workstations to its assigned VLAN network and a router is also added and configured for layer 2 traffic to pass between vlans.
<br />


<h2>Application Used</h2>

- <b>Cisco Packet Tracer</b>
